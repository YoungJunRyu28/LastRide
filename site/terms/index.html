本アプリの使用許諾には、Appleの標準使用許諾契約（Licensed Application End User License Agreement）が適用されます。本規約は、これに加えて本アプリのサービスの利用条件を定めるものです。

2. サービスの内容と情報の正確性

本アプリは、終電・始発の時刻、出発の目安、徒歩時間、タクシー料金の目安、周辺の施設などを表示します。これらは公共交通オープンデータセンターのデータ、Apple Mapsのデータ、および当方の計算に基づく目安であり、正確性・完全性・最新性を保証するものではありません。遅延・運休・ダイヤ改正・交通事情などにより、実際とは異なる場合があります。

本アプリの表示内容について、鉄道事業者その他の公共交通事業者へ直接問い合わせることはお控えください。お問い合わせは当方までお願いします。

4. プレミアム（自動更新サブスクリプション）

  • プランと価格：月額プラン 290円（税込）、年額プラン 1,980円（税込）。価格はApp Storeの表示が優先します。
  • 無料トライアル：初回のみ14日間無料でお試しいただけます。トライアル終了後、選んだプランの料金が自動で請求されます。
  • 自動更新：期間終了の24時間前までに解約しない限り、同じ期間で自動的に更新され、Apple IDに請求されます。
  • 解約：iPhoneの「設定」→ 自分の名前 →「サブスクリプション」から行えます。アプリを削除しただけでは解約されません。
  • 返金：購入・請求・返金はAppleの規定に従い、Appleが行います。当方が直接返金することはできません。
