プライバシーポリシー

最終更新：2026年11月4日（日本国外からのご利用について追記。アプリ削除時に残る情報を明記。11月3日：外部送信先と所在国、安全管理措置、運営者、開示請求の手続を追記）

帰り時（LastRide、以下「本アプリ」）は、アカウント登録なしで使えます。データを広告目的で利用したり、販売したりすることはありません。本ポリシーは、本アプリの運営者（以下「当方」）が本アプリで扱う情報について説明するものです。

端末に保存するもの

  • 保存した帰り先：駅の名前と地域、住所を設定した場合はその住所の文字列。地図上の位置そのものは長期保存せず、必要なときにその夜だけ調べ直します（その夜の終わり、午前4時に消去）。
  • 「今夜だけ別の場所へ」の駅（翌日に自動で消去）
  • 言語、早めに出る時間、通知・アラーム、夜間の位置情報などの設定
  • 今夜のプラン（出発時刻など）。夜が終わると削除または次の夜のものに置き換わります。

移動履歴や過去の夜の記録は保存しません。

位置情報

近くの駅と徒歩時間を調べ、出発時刻を計算するために使います。「夜間の位置情報」で「アプリを閉じても更新」を選んだ場合に限り、アプリを閉じている間も位置情報を使います。案内は終電後（遅くとも午前4時）に自動で止まります。「アプリの使用中のみ」はいつでも設定から選べ、iPhoneの設定で位置情報の許可を取り消すこともできます。

地図と時刻のデータ

iPhoneでは、近くの駅・徒歩時間・住所・周辺の施設・タクシーの所要時間、JRや私鉄の時刻をApple Mapsで調べるため、位置情報と検索内容がApple（Appleのプライバシーポリシーに従います）へ送信されます。

地下鉄などの時刻は、当方のサーバーが公共交通オープンデータセンターのデータで計算するため、出発駅と到着駅（名前と位置）が当方のサーバーへ送信されます。Android版では近くの駅を探すため、iPhoneでもApple Mapsが応答しないときは代わりに、現在地や検索内容（駅名・住所）が当方のサーバーへ送信されます。これらはその問い合わせへの回答にのみ使い、保存せず、個人と結びつけることもありません。

グループ

グループに参加すると、当方のサーバーに次の情報が保存されます：グループ名、グループごとに決めた表示名、ホストかメンバーか、通知の言語と通知の設定、通知用のプッシュトークン、ランダムな参加用トークン（元に戻せない形で保存）、最後に本アプリからアクセスした日時。

「今夜参加する」を選んだ夜は、出発時刻だけが送られ、メンバーには表示名と出発時刻が表示されます。現在地・自宅・駅・経路は共有されません。出発時刻は翌朝8時（日本時間）か、ホストが今夜を終了した時点で削除されます。グループから退出するとあなたの参加データはすぐに削除され、ホストがグループを解散するとすべて削除されます。

プレミアム（サブスクリプション）

購入・請求・返金はApple（App Store）が行い、当方がカード情報などを受け取ることはありません。購読状態の管理にはRevenueCatを使い、氏名やメールアドレスではなく匿名のユーザーIDで管理します（通信の際、RevenueCatには端末のIPアドレスも届きます）。グループを作るとき、当方のサーバーはこのIDで購読状態を確認しますが、IDは保存しません。

通知・アラーム・ウィジェット

出発のリマインダーとアラームは端末の中で予約されます。ウィジェットとロック画面のカウントダウン（ライブアクティビティ）は、今夜の出発時刻を端末の中だけで表示し、当方に送信されることはありません。グループの通知（今夜の開始、メンバーの出発時刻）は、Expoのプッシュ配信サービスとAppleの通知サービスを通じて届きます。通知に広告は含まれません。

クラッシュレポート

アプリの不具合を直すため、エラーの内容・アプリのバージョン・端末とOSの機種、およびこのインストールを区別するランダムなIDをSentry（Functional Software, Inc.）に送信することがあります。位置情報、帰り先、駅、検索内容、表示名は含まれず（送信前に端末で取り除きます）、IPアドレスは保存しない設定にしています。90日後に削除されます。

アプリのアップデート

アプリを開くと、不具合の修正などの更新があるかをExpo（650 Industries, Inc.）のサーバーに確認します。その際、アプリのバージョンと、このインストールを区別するランダムなIDが送られます。位置情報などは含まれません。

当方のサーバーとログ

時刻・駅・所要時間の問い合わせは、当方のサーバーが自前のデータで答え、内容を保存しません。サーバーのログにはアクセス先と結果のみを記録し、位置や検索語を含むURLのパラメータは記録しません。サーバーはAmazon Web Services（東京リージョン）で運用し、グループのデータはNeon（データベース、シンガポール）に保存します。

外部送信と第三者への提供

法令に基づく場合を除き、本人の同意なく個人データを第三者に提供することはありません。本アプリとサイトの機能のため、次の事業者に、それぞれ必要な範囲の情報が送信されます。

  • Apple Inc.（米国）：位置情報と検索内容（近くの駅・徒歩時間・住所・周辺の施設・JRや私鉄の時刻を調べるため）、通知の配信
  • RevenueCat, Inc.（米国）：匿名のユーザーID、購読状態、IPアドレス（プレミアムの管理のため）
  • 650 Industries, Inc.（Expo、米国）：プッシュトークンと通知の内容（グループの通知を届けるため）、アプリのバージョンとインストールごとのID（更新の確認のため）
  • Functional Software, Inc.（Sentry、米国）：エラーの内容、アプリのバージョン、端末とOSの機種、インストールごとのランダムなID（不具合を直すため）
  • Amazon Web Services（日本・東京リージョン）：当方のサーバーへの問い合わせ（時刻・駅の計算、Apple Mapsが使えないときの現在地・検索内容、グループ）
  • Neon, Inc.（データはシンガポールに保存）：グループのデータ（データベース）
  • Cloudflare, Inc.（米国）：このサイトの配信と、お問い合わせフォームの迷惑送信対策

米国・シンガポールにある事業者への送信について：これらの国の個人情報の保護に関する制度は、個人情報保護委員会の「外国における個人情報の保護に関する制度等の調査」で確認できます。各事業者は、それぞれの利用規約・プライバシーポリシーに基づいて情報を取り扱います。

サイトのお問い合わせフォームから送られた内容（お名前・メールアドレス・本文）は、返信のためにメールで当方に届きます。フォームのサーバーには保存しません。迷惑な送信を防ぐため、CloudflareのTurnstileを使います。

削除とお問い合わせ

アプリを削除すると、帰る場所・設定・今夜の予定など、端末に保存された本アプリのデータは消えます。ただし、購読を引き継ぐための匿名のIDと、参加中のグループ（グループ名と参加用の鍵）は、iPhoneのキーチェーンに残ります。再インストールしたときや、バックアップから新しいiPhoneに移したときに、購読と参加中のグループが自動で戻るのはこのためです。グループのデータまで消すには、アプリを削除する前に設定の「データを消去」を使ってください。設定の「データを消去」でも端末のデータを消去でき、その際は参加中のグループからも退出します（ホストの場合はグループを解散し、全員の参加データを削除します）。アプリを削除してもサーバーには伝わらないため、グループのデータは本アプリから6か月間アクセスがないと（通知が届かなくなった場合は30日間で）自動で削除されます（ホストの場合はグループごと削除されます）。すぐに削除したい場合は、アプリを削除する前にグループの「…」から退出してください。

安全管理のための措置

  • 個人データを扱うのは開発者（下記の責任者と共同開発者）のみで、必要な範囲に限ります。
  • アプリ・サーバー・データベース間の通信はすべて暗号化（HTTPS/TLS）し、サーバーとデータベースへのアクセスは開発者のアカウントに限っています。
  • グループの参加用トークンは元に戻せない形で保存し、サーバーのログには位置や検索語を記録しません。不要になったデータは上記の期間で自動的に削除します。
  • 米国・シンガポールにある事業者を利用するため、上記のとおり各国の制度を確認したうえで利用しています（外的環境の把握）。
